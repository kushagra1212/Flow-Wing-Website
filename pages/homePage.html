About Flow-Wing

Flow-Wing is a programming language experiment that combines static and dynamic typing, along with other features. It is still a work in progress and supports object-oriented programming, memory management, garbage collection, and modularity. Flow-Wing includes support for AOT (Ahead-of-Time) and JIT (Just-In-Time) compilers, a REPL, LSP integration for VS Code, build basic servers and basic games

Features of Flow-Wing

Both Static and Dynamic Typing

Flexibly choose typing paradigms based on your needs.

Object-Oriented

Supports object-oriented programming for better data management.

Dynamic and Static Memory Allocation

Offers both memory management techniques for efficiency.

Garbage Collection

Automatic memory management to avoid memory leaks.

Module Support

Easy integration and organization of code into modules.

Compile Time Language

Benefits from compile-time checks to catch errors early.
